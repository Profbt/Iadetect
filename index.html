Como funciona

⬜ Quebras e tabs

Cada U+000A (quebra de linha) aparece como um traço vertical cinza no final da linha. Tabs aparecem como bloco azul-acinzentado. São estrutura, não são removidos.

🟣 Tipografia atípica

Travessões (— –), aspas curvas (" " ' '), reticências (…), bullets (•), primas (′ ″). Opcionalmente normalizáveis para ASCII.

🔵 Espaços especiais

NBSP, thin space, figure space — parecem espaço normal mas têm codepoints diferentes.

🔴 Unicode Tags

Faixa U+E0000–U+E007F usada para esconder instruções em texto aparentemente normal. Presença é sinal forte de manipulação.
